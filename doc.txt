# AI Reality Simulator

## 1. Project Overview

Build a **visual multi-agent simulation platform** where AI characters live inside a virtual company and independently react to real-world events.

The user can trigger an event, and the system simulates how different AI characters **observe, think, communicate, make decisions, and take actions**.

### Example

**Event:** Customer submits a serious complaint.

```text
Customer
   ↓
Complaint
   ↓
Sales Agent
   ↓
CEO Agent
   ↓
Developer Agent
   ↓
Investigation
   ↓
CEO Decision
   ↓
Resolution
```

The entire process appears visually on a **real-time simulation dashboard**.

---

# 2. Main Goal

Create a system that demonstrates:

* Multi-Agent AI
* Agent communication
* Agent memory
* LLM reasoning
* Tool calling
* Event-driven architecture
* Real-time simulation
* Decision making
* Visual AI interactions

The project should feel like a **living virtual company**, not a chatbot.

# 3. AI Characters

Start with 5 agents.

### CEO

Responsibilities:

* Make strategic decisions
* Review important events
* Assign tasks
* Approve major actions

### Sales Agent

Responsibilities:

* Handle customers
* Receive complaints
* Manage leads
* Report customer issues

### Developer Agent

Responsibilities:

* Investigate technical problems
* Analyze logs
* Identify possible bugs
* Propose technical solutions

### Customer Agent

Responsibilities:

* Create requests
* Report problems
* React to company decisions
* Change satisfaction level

### Investor Agent

Responsibilities:

* Monitor company performance
* Review major decisions
* Evaluate business impact

# 6. Agent Workflow

Every event follows a workflow.

Example:

### Customer Complaint

```text
1. Customer creates complaint
        ↓
2. Sales receives complaint
        ↓
3. Sales analyzes issue
        ↓
4. Sales informs CEO
        ↓
5. CEO assigns Developer
        ↓
6. Developer investigates
        ↓
7. Developer reports findings
        ↓
8. CEO decides solution
        ↓
9. Sales communicates resolution
        ↓
10. Customer reacts
        ↓
11. Investor receives business impact
```

Every step should create a visible event in the UI.

---

# 7. Agent Communication

Agents should communicate through structured messages.

Example:

```text
FROM: Sales Agent
TO: CEO Agent

Customer ACME reported a critical payment issue.

Priority: High
Customer Value: $120,000/year
Recommended Action: Immediate technical investigation
```

CEO:

```text
FROM: CEO Agent
TO: Developer Agent

Investigate ACME payment issue.

Priority: Critical
Deadline: Immediate
```

Developer:

```text
FROM: Developer Agent
TO: CEO Agent

Investigation completed.

Root Cause:
Payment API timeout.

Recommended Fix:
Increase timeout and add retry mechanism.
```

# 8. Agent Memory

Each agent should have:

### Short-Term Memory

Current conversation and active task.

### Long-Term Memory

Important historical information.

Example:

```text
Customer:
ACME

History:
- High-value customer
- Previous payment issue
- Prefers fast support
- Contract renewal in 30 days
```

The agent should use memory when making decisions.
